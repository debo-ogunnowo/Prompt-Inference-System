# Prompt-Inference-System
An NLP-driven two-stage system that infers probable student prompts from AI-generated responses and classifies AI usage intent to support academic integrity research.
An NLP-Driven System for Monitoring Student AI Usage and Supporting Academic Integrity

The Prompt Inference System is an NLP-based framework designed to provide insight into how students interact with generative Artificial Intelligence (AI) tools.

Rather than focusing solely on detecting whether a piece of text was generated by AI, the system attempts to infer the probable student prompt that produced an AI-generated response and classify the intent of that prompt.

The system consists of two main components:
1. P-Reconstructor – Reconstructs a probable student prompt from an AI-generated response. 
2. P-Classifier – Classifies the reconstructed prompt according to its intended use of AI.

The system is designed as a research prototype to support academic integrity monitoring and provide educators with additional context about student-AI interactions.
